# Logo files

| File | Size | Used for |
|---|---|---|
| `logo.png` | 512x512 PNG, transparent background | Cursor plugin (`.cursor-plugin/plugin.json`), MCP Registry `icons`, directories |
| `icon-256.png` | 256x256 PNG, transparent background | MCP Registry `icons` (smaller size), client UIs |
| `logo-400.png` | 400x400 PNG, transparent background | Directories that ask for a 400x400 icon (Cline) |

All are the official SuiteDash round badge icon, scaled down from the 1200x1200 original.
